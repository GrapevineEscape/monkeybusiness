# Concept Overview

## Format

**Three-room escape, one group at a time** — not a multi-group circuit, and not one open space with paper "zones."

"Tony's Garage" is three connected physical rooms plus many **containers** inside them:

1. **Main** (Garage Bay) — **largest** / main room
2. **Storage** — **small** room
3. **Office** — **mid-size** room

See [`zones-and-containers.md`](./zones-and-containers.md) for the canonical vocabulary (rooms + containers; older "zone" = room).

### Rooms (exactly three)

1. **Main** — large open garage bay: entrance, "Tony's Garage" sign, Mechanic Station, Mascot Mount, parked car (trunk = container), Frank's upstairs window, etc.
2. **Storage** — small enclosed room off Main; accessed first among the gated rooms.
3. **Office** — mid-size enclosed room off Main; Tony's private desk + personal mechanic station; accessed after Storage.

### Containers (examples — living list in zones-and-containers.md)

Anything that can hold something else: car trunk, Tony's Locker, filing cabinet, desk drawers, lockers, cabinets, boxes, Sparky's battery bay, Tools Closet (proposed as a container in Main — confirm), etc.

## Goal / Win Condition

Restore the garage mascot: open the **car trunk** (container), find Sparky, install the battery (held since early in the game), and return him to the Mascot Mount. That triggers the finale monitor and the YES/NO choice from Tony. Both choices end the game — no "lose" state, only two "win" flavors.

## Access Order (confirmed)

**Room access (gated):** Main (start) → **Storage** → **Office**.

**Major container gate (last):** Car trunk → Sparky → Mascot Mount → finale.

Each gate is a real puzzle (or set of puzzles), not a formality. Smaller containers (lockers, cabinets, drawers) are additional gates/clue holders throughout.

## Room-to-Story Mapping

| Room | Size | Story Role |
|---|---|---|
| Main | Largest | Arrival, Frank's greeting, first impressions, car/trunk (visible container, locked most of the game), Mascot Mount. Early clues: Tony photo + recording about "the Don"/old man. Mechanic Station = candidate physical puzzle. |
| Storage | Small | Accessed first. Handshake photo (Tony + unnamed Chief), bulk evidence. May hold several container gates or one larger puzzle. |
| Office | Mid-size | Accessed second. Labeled Dawn Adams photo (completes triangulation), personal paperwork (calendar, ledger). Where the suspicion turn starts. |
