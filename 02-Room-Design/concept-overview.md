# Concept Overview

## Format

**One room, one group at a time**, not a multi-room-per-group circuit. "Tony's Garage" is a single physical space with **three zones** plus many **containers** inside them.

See [`zones-and-containers.md`](./zones-and-containers.md) for the canonical vocabulary.

### Zones (exactly three)

1. **Main** — open garage bay: entrance, "Tony's Garage" sign, Mechanic Station, Mascot Mount, parked car (trunk = container), Frank's upstairs window, etc.
2. **Storage** — enclosed closet/room, top-right; accessed first among gated rooms.
3. **Office** — enclosed room, bottom-left; Tony's private desk + personal mechanic station; accessed after Storage.

### Containers (examples — living list in zones-and-containers.md)

Anything that can hold something else: car trunk, Tony's Locker, filing cabinet, desk drawers, lockers, cabinets, boxes, Sparky's battery bay, Tools Closet (proposed as a container in Main — confirm), etc.

## Goal / Win Condition

Restore the garage mascot: open the **car trunk** (container), find Sparky, install the battery (held since early in the game), and return him to the Mascot Mount. That triggers the finale monitor and the YES/NO choice from Tony. Both choices end the game — no "lose" state, only two "win" flavors.

## Access Order (confirmed)

**Zone access (gated):** Main (start) → **Storage** → **Office**.

**Major container gate (last):** Car trunk → Sparky → Mascot Mount → finale.

Each gate is a real puzzle (or set of puzzles), not a formality. Smaller containers (lockers, cabinets, drawers) are additional gates/clue holders throughout.

## Zone-to-Story Mapping

| Zone | Story Role |
|---|---|
| Main | Arrival, Frank's greeting, first impressions, car/trunk (visible container, locked most of the game), Mascot Mount. Early clues: Tony photo + recording about "the Don"/old man. Mechanic Station = candidate physical puzzle. |
