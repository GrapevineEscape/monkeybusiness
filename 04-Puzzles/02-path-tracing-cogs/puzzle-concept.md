# Puzzle: Path-Tracing Cogs (working title)

**Status:** Theme HOT; concept from Russell (2026-08-09 / 2026-08-10). Solutions / word / build not locked.  
**Zones:** Pegboard mount TBD (likely Main); cogs found across **three** locations (see distribution).  
**Type:** Multi-zone hunt + physical rotation / overlay path-trace.

---

## Summary

Four colored transparent **cogs** stack on a pegboard. Each cog carries one pathway segment. Players rotate each cog so its path aligns. A continuous line can only be followed **start → finish** once all four cogs are correctly placed and oriented — and that complete path spells a word (or number) by threading through letters.

You cannot finish the line (or reliably guess the word) until all four cogs are on.

---

## Player Experience (as described)

1. Players find a **pegboard** with four small pegs — **red, black, yellow, green**.
2. They find **cogs** over the game (see distribution below). Each cog is a transparent colored disc matching a peg color; each has a **line/path of different lengths** drawn through its center area.
3. Place each cog on its matching colored peg. **Order of stacking does not matter.**
4. Rotate each cog so its pathway segment lines up with the others where they are supposed to meet (overlapping radii / intersections).
5. Attempt to **trace one continuous line** from start to finish through the stacked pathways.
6. With fewer than four cogs, the path **breaks** mid-word — e.g. you can get **STA** but never reach **RR** / **Y** until the missing cog(s) complete the route.
7. With all four cogs correctly rotated: path completes → word (example used in brainstorm: **STARRY**) → unlock / clue payoff TBD.

### Why partial stacks don't spoil it

Russell's playtest intuition: **two cogs are not enough to guess.** Path incompleteness is obvious; the word does not finish until the last pieces land.

---

## Distribution (locked preference)

Cogs are hidden in **three** places, not four:

| Find order | What they get |
|---|---|
| First find | **Cog 1** |
| Second find | **Cog 2** |
| Third find | **Cogs 3 and 4 together** |

**Rationale:** Handing the last two as a pair keeps the end of the path gated until late; early pairs alone stay unguessable.

## Mechanism Notes

| Piece | Role |
|---|---|
| Pegboard + 4 colored pegs | Mount points; color-match is the only "which peg" rule |
| 4 transparent colored cogs | Each = one pathway layer |
| Path segments on each cog | Different lengths; overlap/intersect when rotated correctly |
| Letter field under / through stack | Path threads letters → word when continuous |
| Rotation | Required per cog so segment joints meet |

**Order-independent stack:** red / black / yellow / green can go on in any sequence; success = all four present + each rotated to the matching alignment.

## Difficulty & Fail-Safes

- **Guess resistance:** Designed so ≤2 cogs cannot finish the word; last two arrive together
- **Fail modes:** Wrong color peg; wrong rotation (path doesn't connect); missing cog (path dead-ends)
- **Hint escalation (draft):** (1) color-match pegs → (2) rotate until lines meet → (3) follow the single continuous path for the word
- **Mid-game assist bypass candidate?** Maybe — assist could reveal one missing cog location or the final word if the stack is already complete but unread
- **Reset:** Remove cogs from board; re-hide in three locations; scramble rotations
