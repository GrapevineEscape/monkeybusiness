# Puzzle: Path-Tracing Cogs (working title)

**Status:** Theme HOT; concept from Russell (2026-08-09 / 2026-08-10), alignment update 2026-08-10. Solutions / word / build not locked.  
**Zones:** Pegboard mount TBD (likely Main); cogs found across **three** locations (see distribution).  
**Type:** Multi-zone hunt + physical rotation / overlay path-trace.

---

## Summary

Four transparent **cogs** mount on a pegboard with four pegs. Peg **color does not matter.** Each cog has a **symbol** (think: a funky angled line). The board under/around each peg has multiple candidate symbols/angled lines. Aligning the cog’s symbol with the **one matching** board symbol confirms both: (a) this is the correct peg for that cog, and (b) the cog is rotated correctly.

Each cog also carries one pathway segment. Once all four cogs are on the right pegs at the right rotations, players **trace one continuous line** start → finish through letters to spell a word (or number).

You cannot finish the line (or reliably guess the word) until all four cogs are on.

## Player Experience (as described)

1. Players find a **pegboard** with four pegs. Pegs are not color-coded as the solve key.
2. They find **cogs** over the game (see distribution below). Each is a **transparent** disc with:
   - a **registration symbol** (funky angled line / mark), and
   - a **pathway segment** (line of a given length through the center area).
3. Try a cog on a peg. Look through the transparency: the board shows **multiple** symbols/angled lines near that peg.
4. Rotate until the cog’s symbol **exactly matches** one board symbol. If nothing lines up cleanly → wrong peg (or still wrong rotation). If exactly one match locks in → **right peg + right rotation.**
5. Repeat for remaining cogs. **Order of placing cogs does not matter.**
6. Attempt to **trace one continuous line** from start to finish through the stacked pathways.
7. With fewer than four cogs, the path **breaks** mid-word — e.g. you can get **STA** but never reach **RR** / **Y** until the missing cog(s) complete the route.
8. With all four correctly registered: path completes → word (example used in brainstorm: **STARRY**) → unlock / clue payoff TBD.

### Why the symbol system works

- Transparency lets the player see board marks **through** the cog.
- Multiple board marks near a peg act as distractors; **only one** matches that cog’s mark when seated and rotated correctly.
- Matching is a self-check for both **which peg** and **orientation** — no color coding required.

### Why partial stacks don't spoil it

Russell's playtest intuition: **two cogs are not enough to guess.** Path incompleteness is obvious; the word does not finish until the last pieces land.

## Mechanism Notes

| Piece | Role |
|---|---|
| Pegboard + 4 pegs | Mount points only — **not** color-matched |
| Board symbols / angled lines | Multiple candidates per peg area; one true match per cog |
| Cog registration symbol | Funky angled line (or similar); align with the matching board mark |
| 4 transparent cogs | Each = registration mark + one pathway layer |
| Path segments on each cog | Different lengths; join into one continuous route when all four are registered |
| Letter field under / through stack | Path threads letters → word when continuous |

**Success condition:** all four cogs on correct pegs, each rotated so its symbol matches its unique board mark → pathway continuous → word readable.

## Difficulty & Fail-Safes

- **Guess resistance:** Designed so ≤2 cogs cannot finish the word; last two arrive together
- **Fail modes:** Wrong peg (no symbol match); wrong rotation (symbol doesn't seat); missing cog (path dead-ends)
- **Hint escalation (draft):** (1) look through the cog for a matching mark on the board → (2) only one mark will match when rotation is right → (3) follow the single continuous path for the word
- **Mid-game assist bypass candidate?** Maybe — assist could reveal one missing cog location or the final word if the stack is already complete but unread
- **Reset:** Remove cogs from board; re-hide in three locations; scramble rotations
